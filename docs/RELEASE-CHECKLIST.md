# Release and submission checklist

## Prepared locally

- [x] English README with setup, architecture, limitations, and attribution
- [x] English project description for the submission form
- [x] Timed English script for a video under four minutes
- [x] Windows launcher and two synthetic cases with actual service calls
- [x] Sensitive/local artifacts excluded from Git

## Before publishing (not performed)

- [ ] Review the staged file list and approve publication
- [ ] Choose repository visibility and license for original code
- [ ] Create the GitHub repository and push only reviewed files
- [ ] Verify a clean checkout with separately provisioned services
- [ ] Verify repository access from the reviewer's perspective

## Before submitting (not performed)

- [ ] Record and export the actual demo video, at most 4 minutes
- [ ] Upload the video and verify reviewer access
- [ ] Select the competition track and review its current rules
- [ ] Paste the 150–2000 character description, repository URL, and video URL
- [ ] Optional: add a pitch deck
- [ ] Review the completed form before final submission

The repository package does not include licensed Zetaris software, Nightshift binaries, local credentials, or model files. Reviewers must provision these dependencies. Do not interpret local integration success as clean-machine verification.
