The question

More players joined the live event. So why did revenue fall?

A game team sees this after an event and has to explain it before the next one. A guess is easy to make and hard to check. LiveOps Investigator tests each possible explanation against SQL evidence, remembers what it found, and lets you challenge every step.

  1. MeasureZetaris runs the SQL behind every number on this page.
  2. Choose where to lookH-MEM recalls earlier evidence. Nightshift's local model gives advice that is recorded but never decides.
  3. Test and showEach explanation is checked against a stated rule, with its data one click away.
  4. ChallengeDispute a number, ask for another comparison, or reject a finding. The agent re-queries and updates its memory.

What this does not claim

The game data is synthetic aggregate metrics written as inline SQL, not production telemetry. Findings show where to look next; they are not proof of cause. The order of checks comes from a fixed memory rule, both checks always run, and the model never produces a number or a verdict.
